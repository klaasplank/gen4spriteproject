How to name the files:
Assume NAME is the name of the Pokémon
Add the Pokédex number in front of the filename! For example: 25PikachuFront.png

__Modern__
Images are at 80x80 size for front and back sprites

Front, non shiny: 000NAMEFront.png
Front, shiny: 000NAMEFrontShiny.png
Back, non shiny: 000NAMEBack.png
Back, shiny: 000NAMEBackShiny.png

In case of gender differences: For female, don't add anything. For male, add “Male” after the last word (so for example “000NameFrontShinyMale.png)

For alternate forms, check the claimsheet to see the naming. The form name comes right after “NAME”.

__Icon__
Images are at 64x32 size for the icon sprites with the two frames being next to eachother (each being limited to 32x32)  
000NAMEIcon.png

__Classic__
Images are at 160x80 size for front and back sprites, with the 80x80 first and second frame sprites being right next to eachother

Front, non shiny: 000NAMEFront.png
Front, shiny: 000NAMEFrontShiny.png
Back, non shiny: 000NAMEBack.png
Back, shiny: 000NAMEBackShiny.png
