How to name the files:
Assume NAME is the name of the Pokémon
Add the Pokédex number in front of the filename! For example: 25PikachuFront.png

Modern
Images are at 80x80 size for front and back sprites, and 32x32 for the icon sprites

Front, non shiny: NAMEFront.png
Front, shiny: NAMEFrontShiny.png
Back, non shiny: NAMEBack.png
Back, shiny: NAMEBackShiny.png
Icon: NAMEIcon.png

In case of gender differences: add “Male” after the last word (so for example “NameFrontShinyMale.png)

For alternate forms, check the claimsheet to see the naming. The form name comes right after “NAME”.

Classic
Images are at 160x80 size for front and back sprites, with the 80x80 first and second frame sprites being right next to eachother 
64x32 for the icon sprites with the two frames being next to eachother as 32x32

Front, non shiny: NAMEFront.png
Front, shiny: NAMEFrontShiny.png
Back, non shiny: NAMEBack.png
Back, shiny: NAMEBackShiny.png
Icon: NAMEIcon.png
